# Experiment: Creating a MetaMask Wallet for Crypto Transactions

## Aim

To create and configure a personal MetaMask wallet for cryptocurrency
transactions and interaction with Ethereum-compatible decentralised applications.

## Theory

MetaMask is a self-custodial cryptocurrency wallet used to manage blockchain
accounts and interact with Ethereum and compatible blockchain networks. It is
available as a browser extension and mobile application.

MetaMask allows a user to:

- Create and manage blockchain accounts.
- Send and receive Ether and supported tokens.
- Connect to decentralised applications (DApps).
- Sign messages and approve blockchain transactions.
- View account addresses, balances, and transaction activity.
- Manage multiple accounts in one wallet.

In a self-custodial wallet, the user controls the private keys. The secret
recovery phrase is the backup for the wallet and must be kept private. Anyone who
has the recovery phrase may be able to control the wallet's funds. MetaMask does
not recover a lost recovery phrase.

Every transaction that changes the blockchain requires a network fee. On Ethereum,
this fee is paid in Ether and is commonly called the gas fee. The amount depends
on the gas used and the network fee rate. The user can review the estimated fee
in MetaMask before confirming a transaction.

## Requirements

- Google Chrome, Microsoft Edge, Mozilla Firefox, or another supported browser.
- An internet connection.
- The official MetaMask browser extension or mobile application.
- A test network or local blockchain for practice.
- A trusted place to store the secret recovery phrase offline.

## Procedure

### Step 1: Install MetaMask

1. Open the official MetaMask website:
   <https://metamask.io/>
2. Select the browser or mobile platform being used.
3. Follow the link to the official browser store or application store.
4. Verify that the publisher is MetaMask or Consensys.
5. Click **Add to Chrome**, **Add to Firefox**, or the equivalent installation
   button.
6. Review the requested permissions and confirm the installation.
7. Open MetaMask from the browser toolbar or application menu.

Do not install MetaMask from an unknown website, advertisement, or unofficial
download link.

### Step 2: Start wallet setup

1. Click **Get started**.
2. Select **Create a new wallet**.
3. If an existing wallet is being restored, select **Import an existing wallet**
   instead.
4. Review the privacy and usage options.
5. Select **I Agree** or **No Thanks**, according to the required preference.

### Step 3: Create a password

1. Enter a strong password.
2. Confirm the password.
3. Accept the terms of use.
4. Click **Create** or **Next**.

The MetaMask password protects the wallet on the current browser profile. It is
not the secret recovery phrase and cannot replace it.

### Step 4: Secure the secret recovery phrase

1. MetaMask displays a secret recovery phrase.
2. Write the phrase on paper and store it in a secure place.
3. Confirm the phrase by selecting the words in the requested order.
4. Complete the wallet setup.

Never:

- Share the phrase with anyone.
- Send it by email, chat, or social media.
- Store it in a screenshot or an online document.
- Enter it into an unknown website.
- Commit it to a source-code repository.

MetaMask support will not ask for the secret recovery phrase.

### Step 5: Review the wallet account

1. Open the MetaMask extension.
2. Check the selected account name, such as **Account 1**.
3. Copy the public wallet address when required.
4. Use the account address to receive Ether or supported tokens.
5. Confirm that the selected network is correct before using the address.

The public address may be shared to receive funds. It is different from the
private key and secret recovery phrase, which must remain private.

### Step 6: Configure wallet settings

1. Open the account menu.
2. Review the account name and notification settings.
3. Review the connected sites and disconnect unknown applications.
4. Enable suitable security and privacy settings.
5. Add another account only when required.

### Step 7: Deposit or receive test funds

1. Select the account.
2. Click **Receive** or **Copy address**.
3. Copy the public address.
4. Send only test Ether from a faucet or another test account when practising.
5. Wait for the transaction confirmation.
6. Verify the balance and transaction history.

For a classroom demonstration, use a test network or local blockchain. Do not
send real funds while learning.

### Step 8: Perform a test transaction

1. Select **Send**.
2. Enter the recipient's public address.
3. Enter the amount of test Ether.
4. Check the recipient address and selected network carefully.
5. Review the estimated gas fee and total amount.
6. Click **Confirm**.
7. Open the activity or transaction details.
8. Record the transaction hash and final status.

Blockchain transactions are generally irreversible. A transaction sent to the
wrong address or network may not be recoverable.

## MetaMask Fees and Gas

MetaMask does not control the blockchain gas fee. The fee is determined by the
network and the transaction's gas usage.

```text
Network fee = Gas used x Effective gas price
```

The transaction confirmation window may show:

- Ether value being sent.
- Estimated gas fee.
- Maximum fee or fee limit.
- Total amount deducted.

The final fee may differ from the estimate. A failed transaction may still
consume gas because the network used resources to process it.

## Result

A MetaMask wallet was created and configured successfully. The public wallet
address was identified, test funds were received, and the process of sending a
cryptocurrency transaction and reviewing its gas fee was studied.

## Precautions

- Download MetaMask only from the official source.
- Verify the network before sending funds.
- Verify the recipient address character by character.
- Never share the secret recovery phrase or private key.
- Reject unknown signature and transaction requests.
- Use a test network or local blockchain for practical work.
- Keep the wallet password and recovery phrase in separate secure locations.
- Remember that blockchain transactions are usually irreversible.
